## 1. 制造一次真实崩溃

1. 浩辰CAD 里新建图纸，**画三样东西**并留个记号：
   - 三个圆
   - 一段文字：`CAD-DRILL-2026-10-24`
   - 一条直线
   **不要保存**
2. 输入 `OPTIONS`（或「工具 → 选项」）→「打开和保存」→ 勾「自动保存」，间隔设 **1 分钟**
3. 等 **90 秒以上**，然后看 `%LOCALAPPDATA%\Temp` 里有没有 `*.sv$`：

```powershell
Get-ChildItem "$env:LOCALAPPDATA\Temp" -Filter '*.sv$' -File |
  Select-Object Name, Length, LastWriteTime | Format-Table -AutoSize
```

4. 出现了 → **记下文件名**，然后**用任务管理器结束 `gcad.exe` 进程树**（结束进程，不是「关闭」）

> 这一步是「被杀」不是「自崩」：哨兵会判 `unknown-exit`（无崩溃证据）。这正是要验证的分支之一。
> 想验 `crash-suspected`（有崩溃证据）得让它真崩，不可控，不作必做项。

## 2. 看工具发现了什么（应在 3 秒内）

```powershell
Get-Content E:\ai\_tools\errwatch\sentinel-pending.json -Raw | ConvertFrom-Json |
  Select-Object app, verdict, coverage, coverageReason, latencyMs, latencySource | Format-List
```

要记的四个数：

| 指标 | 从哪读 | 本次值 |
|---|---|---|
| 发现延迟 | `latencyMs` | ______ |
| 判定 | `verdict`（unknown-exit / crash-suspected） | ______ |
| 可信度 | `coverage` + `coverageReason` | ______ |
| 是否跨盲区 | `latencySource`（observed / after-gap） | ______ |

## 3. 救援 + 验证「内容真的救得回来」（C1 的核心）

```powershell
# ① 找候选（只读）
pwsh -File E:\ai\_tools\errwatch\errwatch-recover.ps1 -App gcad

# ② 复制到你自己选的目录（只复制，原文件不动）
pwsh -File E:\ai\_tools\errwatch\errwatch-recover.ps1 -App gcad -SaveTo "D:\cad-rescue-test"
```

然后**手工**验证：

1. 进 `D:\cad-rescue-test`，把那份 `*.sv$` **再复制一份**，副本改名为 `*.dwg`
2. 用浩辰CAD 打开这个 `.dwg`
3. 看三个圆、那条线、文字 `CAD-DRILL-2026-10-24` 在不在

结果三选一，请如实记：

| 结果 | 含义 | 我要改什么 |
|---|---|---|
| **能打开、内容都在** | `.sv$` 恢复成立 | `convert` 文案定稿；`recover.json` 的 gstarcad 条目算验证通过 |
| **能打开、缺最后一段** | 最后一次自动保存之后的丢了 | 建议把间隔从 5 分钟降到 1–2 分钟 |
| **打不开 / 提示损坏** | 最重要的一条 | 把「图形恢复管理器」提到第一步，不能只教「改名」 |

## 4. 顺带确认的一件事

`errwatch-recover -App gcad` 输出里有这么一句：

> 只找到 %TEMP% 这类通用目录，找不到它自己的恢复目录 —— 装的这个版本可能换了路径（路径表要更新），或是绿色版

对浩辰来说这句是**误报**：它的自动保存**本来就落在通用临时目录**（注册表 `SAVEFILEPATH` 实测如此）。
演练完我会按你的结果改这条文案 —— 让「已知落在通用目录」的程序不再被怀疑「换了路径」。
