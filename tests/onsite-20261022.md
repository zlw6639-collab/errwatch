## 阶段 A：安全模式（验证 L2 判定）

> ⚡ **快捷方式**：`E:\ai\safe.cmd` 已生成并在本机测过。安全模式里只需运行它：
> **`E:\ai\safe.cmd`** —— 它会用 `powershell.exe`（5.1，不依赖 pwsh）跑 `errwatch.ps1` 与修复器（验证被拒绝），
> 结果写进 `E:\ai\safe-test.log`，最后 `pause` 让你看输出。回正常系统我读日志分析。
> （`errwatch.ps1` 已补 UTF-8 BOM，5.1 下实测通过。）

### 步骤

1. `Win + R` → 输入 `msconfig` → 回车
2. **引导** 选项卡 → 勾选 **安全启动** → 选 **最小** → 确定
3. 弹窗问是否重启 → **重新启动**
4. 进桌面后，屏幕四角会显示「安全模式」（桌面是黑的、壁纸没了，这是正常的）
5. 打开 PowerShell：开始菜单 → 搜索 `PowerShell` → 右键 **以管理员身份运行**（普通也行）
6. 逐条执行（第二条顺带验证"安全模式下修复默认被拒"）：

```powershell
cd E:\ai\_tools\errwatch
pwsh -File .\errwatch.ps1 -Hours 2
```

> 如果提示"pwsh 不是内部或外部命令"（安全模式下商店版可能不可用），改用：
> `powershell -File .\errwatch.ps1 -Hours 2`

```powershell
.\errwatch-fix.ps1 -Action log-rotate -Path E:\ai\_tmp\demo.log
```
（**不应该**执行，应提示"安全模式默认拒绝，需要 -AllowSafeMode"）

7. 退安全模式：`msconfig` → 引导 → **取消**勾选安全启动 → 确定 → 重启

### 要记录的三件事

- 报告开头 **「运行模式：」** 那一行原文
- 「上次成功采集」那一行、以及下面有没有安全模式提示块
- 第 6 步第二条命令的输出（是否被拒绝、提示原文）

## 阶段 B0：WinRE（**不用 U 盘**，当前主方案）

> U 盘坏了（可移动盘「无媒体」），改用本机硬盘。errwatch 在 `E:\ai\_tools\errwatch`，
> 证据包写到 `E:\ai\bundle-winre`（非系统盘，不碰 C 盘上的系统文件）。

> ⚡ **快捷方式**：`E:\ai\go.cmd` 已生成并在正常系统测过（退出码 0）。
> WinRE 里只要输入 **`E:\ai\go.cmd`** 一条命令即可：它自动找 errwatch、自动探测系统盘、
> 自动写到 `E:\ai\bundle-winre`，结束会 `pause` 让你看结果。下面 3~4 步是手动等价版。

### 1. 准备（在正常系统里，1 分钟）

```powershell
New-Item -ItemType Directory -Force E:\ai\bundle-winre | Out-Null
Test-Path E:\ai\_tools\errwatch\runners\L3-collect.cmd   # 必须返回 True
```

### 2. 直接重启到恢复环境（不依赖设置界面）

```powershell
shutdown /r /o /t 0
```

电脑会重启并进入「选择一个选项」→ **疑难解答** → **高级选项** → **命令提示符**。
（这是命令行的"高级启动"，比设置里点更稳，尤其 explorer 现在不正常。）

### 3. 在 WinRE 的命令提示符里（默认在 `X:\Sources>`）

WinRE 里**盘符会重排**，先找 errwatch 在哪：

```cmd
for %d in (C D E F G H) do @if exist %d:\ai\_tools\errwatch\runners\L3-collect.cmd echo FOUND %d:
```

看到 `FOUND E:` 之类就用那个盘符（大概率还是 E:）：

```cmd
E:
cd \ai\_tools\errwatch\runners
L3-collect.cmd  E:\ai\bundle-winre  C:
```

- 第一个参数 = 证据包输出目录（非系统盘）
- 第二个参数 = 目标系统盘（`C:`）
- 约 1~3 分钟（要拷两份约 20MB 的事件日志）

### 4. 采完立刻看清单

```cmd
type E:\ai\bundle-winre\manifest.json
```

重点：`"items"` 里应出现 `System.evtx` / `Application.evtx`（`kind` 为 `eventlog`）；
`"missing"` 里**不应**再出现 `disk` / `registry` / `packages`（WinRE 里你是管理员，这些应该都能采到）。

### 5. 退出并回到正常系统

```cmd
exit
```

回到「选择一个选项」→ **继续** → 正常启动。

### 6. 回来后分析（正常系统里）

```powershell
pwsh -File E:\ai\_tools\errwatch\errwatch-bundle-analyze.ps1 -Bundle E:\ai\bundle-winre
```

### 要记录的四件事

1. `for` 那条命令输出的是哪个盘符
2. `L3-collect.cmd` 最后几行（退出码、条目数）
3. `manifest.json` 的 items 条目数 + missing 列表
4. 分析报告「关键事件」那几节的标题（有没有出现「事件 0」「蓝屏 878 次」这类旧误报）

## 阶段 B1：WinRE（有 U 盘时的原方案）


### 准备

1. 把 `E:\ai\_tools\errwatch` **整个目录**拷到 U 盘根目录 → `U:\errwatch`
2. 记住 U 盘在系统里的盘符（比如 `F:`）

### 进 WinRE

推荐这条路（不用等强制关机）：

1. 设置 → 系统 → 恢复 → **高级启动** → 立即重新启动
2. 疑难解答 → 高级选项 → **命令提示符**
3. 看到 `X:\Sources>` 就到位了（**X: 是内存盘，不是你的系统盘**）

备选：开机出现 logo 时按住电源键 5 秒强制关机，重复 3 次，第 4 次会自动进"自动修复"。

### 采集

```cmd
dir U:\            ← 确认盘符（把 U: 换成你 U 盘的真实盘符）
U:
cd \errwatch\runners
L3-collect.cmd  U:\bundle  C:
```

- 第二个参数是**证据包输出目录**（放 U 盘，别放 C 盘）
- 第三个参数是**目标系统盘**（通常 `C:`；不确定就先 `dir C:\Windows` 看看）
- 约 1~3 分钟（要拷两份约 20MB 的事件日志）

### 采完看结果

```cmd
type U:\bundle\manifest.json
```

重点看两处：`"items"` 里有没有 `System.evtx` / `Application.evtx`（`kind` 为 `eventlog`），
`"missing"` 里有没有不该缺的东西（WinRE 里是管理员，`disk` / `registry` / `packages` 应该都在）。

然后 `exit` 退出命令提示符，正常重启回系统。

### 回来后分析

```powershell
pwsh -File E:\ai\_tools\errwatch\errwatch-bundle-analyze.ps1 -Bundle U:\bundle
```

（或把 U 盘里的 `bundle` 拷到 `E:\ai\_tmp\bundle` 再分析）

### 要记录的三件事

- `L3-collect.cmd` 最后几行（退出码、条目数）
- `manifest.json` 里 `items` 的条目数与 `missing` 的列表
- 分析报告里「关键事件」那几节的标题
