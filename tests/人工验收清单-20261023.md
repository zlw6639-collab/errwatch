## 八、出问题怎么报

只需要告诉我两件事：

1. **编号**（如 `5.5`）
2. **现象**（一句话，比如"黑窗口里中文是乱码"）

如果界面**整个消失**了，先看这个文件在不在：

```
E:\ai\_tools\errwatch\ui-crash.log
```

在 → 发我内容（真崩溃，有堆栈）
不在 → 是被关掉/被结束的，不是 bug
