## 二、逐项结论

### 2.1 授权绑定 —— ✅ 通过

预览与执行使用**同一组变量**（`$Path/$Name/$File/$Field/$Value`），中间无二次输入。

- 演练分支：`if (-not $Commit) { ... Done 'dry-run' }`
- 执行分支：直接使用同一变量

**不存在"预览 A、执行 B"的代码路径。**

### 2.2 `-Force` 边界 —— ✅ 已收紧

**修复前**：任何动作都可带 `-Force`（虽然实际只影响 log-rotate）。

**修复后**（fix.ps1:80-84）：
```powershell
if ($Force -and $Action -notin @('log-rotate')) {
    Fail "-Force 只对 log-rotate 生效（当前动作: $Action）..."
}
```

**实测**：
```
restart-service -Force → STATUS: refused
check -Force           → STATUS: refused
log-rotate -Force      → 正常（演练通过）
```

`-Force` 现在**只绕过扩展名白名单**，不影响参数校验、权限检查、其他动作。

### 2.3 通配符注入 —— 🔴 已证实问题（已修复）

**问题**：`Get-Process -Name` / `Get-Service -Name` 支持通配符，`-Name "QQ*"` 会匹配多个目标。

**修复前实测**：
```
restart-process -Name "QQ*"     → 匹配到 1 个（若有多进程会全杀）
restart-service -Name "wuaus*"  → 匹配到 wuauserv（非预期）
```

**修复**（两处）：
```powershell
if ($Name -match '[*?]') { Fail "-Name 不支持通配符..." }
```

**修复后实测**：
```
restart-process -Name "QQ*"     → STATUS: refused
restart-service -Name "wuaus*"  → STATUS: refused
```

### 2.4 参数注入 —— ✅ 通过

**实测**：
```
restart-service -Name "wuauserv; calc"
→ [拒绝] 服务不存在：wuauserv; calc
```

PowerShell 参数化调用不解析分号，无命令注入面。

### 2.5 TOCTOU（检查后目标被替换）—— ⚠️ 存在理论窗口

`log-rotate` 的代码路径：
```
Test-Path $Path → Get-Item $Path → Copy-Item $Path → Clear-Content $Path
```

**检查与使用之间有多步，理论上可被并发替换。**

**实际风险评估**：本地单用户工具，并发替换目标需要另一个进程精确操作同一路径，且替换后仍要通过后续大小校验。**低风险，未修复**，但记录在案。

### 2.6 并发/重复 —— ✅ 通过

**锁**：`[System.IO.File]::Open($lockPath, 'CreateNew', 'Write', 'None')` + `finally` 释放。

**实测**：
```
手动占用锁 → [拒绝] 另一个修复正在执行
释放后     → 正常
多次执行   → 锁文件不残留
```

### 2.7 审计失败 —— 🔴 已证实问题（已修复）

**修复前**：`Write-Audit` 失败只打印警告，**继续执行**。

**修复后**：执行点传 `-Critical`，审计写不进去则 `Fail`（fail closed）。

**修复后实测**：5 个执行点全部带 `-Critical`（fix.ps1:129/176/232/285/364）。
