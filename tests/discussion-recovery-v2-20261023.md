# 恢复机会 V2：待讨论的问题清单（2026-10-23）

> 用途：给另一个人/AI 接手讨论用。只写**已确认的事实**与**待拍板的取舍**，不含结论式承诺。
> 配套已落地部分见 `design-recovery-opportunity-20261023.md`；当前包 `errwatch-20261023-al.zip`。

## 一、实测事实（本机 WZL，不是推测）

1. **旧路径表 6 漏 4**：VS Code Backups / VS Code History / Notepad++ backup / Office UnsavedFiles 四个目录都不存在；Word 与 TEMP 存在但近 7 天 0 文件。
2. **`%TEMP%` 被重定向**：当前进程 `$env:TEMP = C:\Users\<用户>\AppData\Local\Temp\dsh-UXuUHX`，标准位置是 `AppData\Local\Temp`。
   → **同一个程序从不同入口启动，autosave 会写到不同目录**；errwatch 若从别的宿主启动，会扫错地方。
3. **`AppData\Local\Temp` 顶层 0 文件**（被清理过）。而 AutoCAD 的 autosave **默认就写在这里**。
4. `%APPDATA%\Microsoft\Word` 有 1 个 `.asd` 残留，未见有人处理。
5. **不同应用的「丢失窗口」差 3 个数量级**：VS Code 是事件驱动（每次改动写备份，≈0）；Word/Excel（`AutoRecoverTime`）与 AutoCAD（`SAVETIME`）默认都是 **10 分钟**。

## 二、已经确定的技术判断

- autosave 是**定时器到点才写盘**，崩溃那一瞬间不写 → 崩溃前最后 0～10 分钟必然丢，事后救援救不回来，只能靠缩短间隔。
- 「恢复」是**下一次启动时的进程行为**，不是文件还在就自动回来。
- 只按 mtime 倒序排候选会误导（上周的 `.sv$` 排第一）→ 必须与会话起点（进程 StartTime / 哨兵登记）交叉分档。
- 「持续保留机会」拆成：**持续登记（便宜、只读元数据）** + **故障后取内容（贵、用户点了才做）**。

## 三、应用自己会失败的地方（6 个断点）

1. 写盘失败（目录不存在 / 磁盘满 / 权限）
2. **写在会被清理的位置**（CAD → `%TEMP%`）
3. 恢复面板**只在下一次启动弹一次**，用户点关闭就不再问
4. 用户急着重开，恢复面板问「要不要恢复」时手滑点「否」→ 文件被删
5. 升级后旧格式读不回
6. 崩溃时正好在写 autosave → 留下半截文件，应用自己反而读不了

## 四、四个候选「帮一把」（按侵入性排序）

| # | 做法 | 解决哪个断点 | 代价 / 风险 |
|---|---|---|---|
| ① | **崩溃瞬时留底**：崩溃事件后、应用重启前，把候选**复制**到 `%LOCALAPPDATA%\errwatch\rescue\<时间>\` | 2、3、4、6 | 磁盘占用；内容是隐私（本地）；**唯一能真正救回内容的手段** |
| ② | 建议把 autosave 目录**挪出 `%TEMP%`**（CAD 选项里可改） | 2 | 零成本，只提示、不自动改 |
| ③ | 崩溃后第一句提示「**在恢复之前先别重开它**」 | 3、4 | 零成本 |
| ④ | 把间隔从 10 分钟压到 **2～5 分钟** | 减少丢失量 | 零成本，只提示；频率过高会略微影响性能 |

## 五、待拍板的取舍（需要人给判断）

1. **①要不要做**？做了才叫「真能救回」；不做就永远只能「指路」。
2. 若做：**默认开还是默认关**？谁授权（首次询问 vs 配置项）？
3. **大小上限**：单文件？单次？总量？（建议单文件 50 MB / 单次 200 MB 起步）
4. **保留多久**：3 天 / 7 天 / 到用户手动清？
5. **复制哪些**：只复制「本次会话」这一档（保守，误报少）还是全部候选（激进，可能复制一堆旧垃圾）？
6. **只在崩溃时留底，还是正常退出也留底**？后者等于备份，风险与磁盘成本完全不是一个量级。
7. **是否要排除某些扩展名/目录**（隐私敏感文件）？
8. 留底目录要不要加密？（本项目无证书、无密钥管理，加装加密会显著增加攻击面）
9. ②的「挪位置」要不要帮用户改注册表？—— **倾向不要**，只提示，避免替用户改系统设置。

## 六、明确劝退的方向

- hook 拦截崩溃 / 注入 DLL：反作弊红线（VAC/EAC/BattlEye）+ 稳定性
- 内存 dump / 从 dump 重建文档：能说「怎么崩的」，基本救不回内容
- 定时截屏：隐私灾难，且还原不出文本
- 进程级 checkpoint：**Windows 没有 CRIU 这种东西**
